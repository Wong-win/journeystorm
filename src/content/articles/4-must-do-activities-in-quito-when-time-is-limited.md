<p>Quito, regorgeant de sites captivants, est un défi à explorer pleinement en une seule journée. Cependant, si c'est tout le temps dont vous disposez dans la capitale équatorienne de haute altitude, se concentrer sur ses attractions les plus emblématiques est essentiel. Le centre historique classé à l'UNESCO est une visite incontournable. Voici quatre expériences essentielles à Quito quand le temps presse.</p>
<h3><strong style="border: 0px solid #d9d9e3; box-sizing: border-box; --tw-border-spacing-x: 0; --tw-border-spacing-y: 0; --tw-translate-x: 0; --tw-translate-y: 0; --tw-rotate: 0; --tw-skew-x: 0; --tw-skew-y: 0; --tw-scale-x: 1; --tw-scale-y: 1; --tw-scroll-snap-strictness: proximity; --tw-ring-offset-width: 0px; --tw-ring-offset-color: #fff; --tw-ring-color: rgba(69,89,164,.5); --tw-ring-offset-shadow: 0 0 transparent; --tw-ring-shadow: 0 0 transparent; --tw-shadow: 0 0 transparent; --tw-shadow-colored: 0 0 transparent; font-weight: 600; color: var(--tw-prose-bold); margin-top: 1.25em; margin-bottom: 1.25em;">1. Compania de Jesus</strong></h3>
<p><img decoding="async" src="https://img.atlasobscura.com/mouYFDVyFXGvexhTsjsun_smvFVs2_hVioyMOQPjB_Q/rt:fit/h:390/q:81/sm:1/scp:1/ar:1/aHR0cHM6Ly9hdGxh/cy1kZXYuczMuYW1h/em9uYXdzLmNvbS91/cGxvYWRzL3BsYWNl/X2ltYWdlcy82Yzhi/NmNiNC01ZGY3LTQ2/ODMtYmNkZS01ZDQ5/OWZlMGRjOTNjZTlj/NWMzMGE5MmQ5YzU1/ZGJfSWdsZXNpYV9k/ZV9MYV9Db21wYcOx/w61hLF9RdWl0b18x/LkpQRw.jpg" alt="Iglesia de la Compañía de Jesús – Quito, Ecuador - Atlas Obscura" /></p>
<p>L'église de la Compagnie de Jésus est l'une des plus belles églises de Quito, dotée d'une riche histoire. Sa construction s'est étalée sur plus de 160 ans, comme en témoignent ses superbes moulures en stuc, ses sculptures et sa décoration. Cette église n'est pas seulement un lieu religieux ; c'est un monument historique qui transcende les croyances personnelles et constitue une visite incontournable pour quiconque vient à Quito.</p>
<h3><strong style="border: 0px solid #d9d9e3; box-sizing: border-box; --tw-border-spacing-x: 0; --tw-border-spacing-y: 0; --tw-translate-x: 0; --tw-translate-y: 0; --tw-rotate: 0; --tw-skew-x: 0; --tw-skew-y: 0; --tw-scale-x: 1; --tw-scale-y: 1; --tw-scroll-snap-strictness: proximity; --tw-ring-offset-width: 0px; --tw-ring-offset-color: #fff; --tw-ring-color: rgba(69,89,164,.5); --tw-ring-offset-shadow: 0 0 transparent; --tw-ring-shadow: 0 0 transparent; --tw-shadow: 0 0 transparent; --tw-shadow-colored: 0 0 transparent; font-weight: 600; color: var(--tw-prose-bold); margin-top: 1.25em; margin-bottom: 1.25em;">2. La Plaza de La Independencia</strong></h3>
<p><img decoding="async" src="https://www.clave.com.ec/wp-content/uploads/2015/08/MG_2001.jpg" alt="Plaza de la Independencia - Clave!" /></p>
<p>Au cœur de Quito se trouve la place de l'Indépendance, un point central pour les grands événements et qui abrite certains des plus élégants palais de l'Équateur. La meilleure façon d'apprécier ses attraits est de participer aux visites guidées gratuites proposées à Quito, qui commencent ou se terminent souvent ici. Ces visites sont essentielles pour une compréhension complète des points forts de la ville en une journée. La pièce maîtresse de la place est un monument en l'honneur de l'indépendance du Pérou, érigé en 1898 et symbolisant la liberté pour le peuple.</p>
<h3><strong style="border: 0px solid #d9d9e3; box-sizing: border-box; --tw-border-spacing-x: 0; --tw-border-spacing-y: 0; --tw-translate-x: 0; --tw-translate-y: 0; --tw-rotate: 0; --tw-skew-x: 0; --tw-skew-y: 0; --tw-scale-x: 1; --tw-scale-y: 1; --tw-scroll-snap-strictness: proximity; --tw-ring-offset-width: 0px; --tw-ring-offset-color: #fff; --tw-ring-color: rgba(69,89,164,.5); --tw-ring-offset-shadow: 0 0 transparent; --tw-ring-shadow: 0 0 transparent; --tw-shadow: 0 0 transparent; --tw-shadow-colored: 0 0 transparent; font-weight: 600; color: var(--tw-prose-bold); margin-top: 1.25em; margin-bottom: 1.25em;">3. Basilica del Voto Nacional</strong></h3>
<p><img decoding="async" src="https://marketingsimulator.net/enriquealtamirano/wp-content/uploads/sites/551/2017/07/bas%C3%ADlica-del-voto-nacional_1.jpg" alt="Basílica del Voto Nacional - Bellezas Latinoamericanas | Quito" /></p>
<p>Préparez-vous à être surpris par la Basilique du Vœu National, surtout si vous pensez avoir déjà vu tous les styles d'églises. Sa beauté et son design unique, avec des tatous remplaçant les gargouilles traditionnelles, la distinguent des autres structures néo-gothiques. Un aspect intrigant de cette église est un café niché dans ses niveaux supérieurs, offrant la possibilité de se détendre avec une bière. L'ascension jusqu'au sommet vous récompense par l'une des vues les plus époustouflantes de la ville de Quito.</p>
<h3><strong style="border: 0px solid #d9d9e3; box-sizing: border-box; --tw-border-spacing-x: 0; --tw-border-spacing-y: 0; --tw-translate-x: 0; --tw-translate-y: 0; --tw-rotate: 0; --tw-skew-x: 0; --tw-skew-y: 0; --tw-scale-x: 1; --tw-scale-y: 1; --tw-scroll-snap-strictness: proximity; --tw-ring-offset-width: 0px; --tw-ring-offset-color: #fff; --tw-ring-color: rgba(69,89,164,.5); --tw-ring-offset-shadow: 0 0 transparent; --tw-ring-shadow: 0 0 transparent; --tw-shadow: 0 0 transparent; --tw-shadow-colored: 0 0 transparent; font-weight: 600; color: var(--tw-prose-bold); margin-top: 1.25em; margin-bottom: 1.25em;">4. TeleferiQo</strong></h3>
<p><img decoding="async" src="https://ec.viajandox.com/uploads/attractive_2188.jpg" alt="Teleférico Quito Ecuador" /></p>
<p>Un tour en TeleferiQo est une expérience essentielle à Quito, surtout quand le temps est limité. Ce trajet en téléphérique offre des vues panoramiques époustouflantes et vous transporte de l'agitation de la ville vers des paysages de montagne sereins. Au sommet, saisissez l'occasion de prendre des photos de lamas et de vous détendre dans un café pittoresque.</p>
<p>Ces quatre points forts offrent un aperçu de la riche tapisserie culturelle et historique de Quito, parfait pour ceux qui n'ont qu'une journée à consacrer à cette ville enchanteresse.</p>
